# Captures d'écran

Images utilisées par la documentation. Déposer les fichiers ici, puis
décommenter la ligne `![…](images/…)` dans le doc concerné.

| Fichier | Doc | Contenu attendu |
|---------|-----|-----------------|
| `sortie-couleurs.png` | [usage.md](../usage.md#couleurs) | rapport complet dans un terminal, statuts colorés (rouge / vert / bleu) |
| `install-release.png` | [install.md](../install.md#captures-décran) | page Release GitHub avec les 5 assets |
| `install-premier-run.png` | [install.md](../install.md#captures-décran) | premier lancement du binaire depuis `~/bin` |

Conventions : PNG, largeur ≤ 1400 px, terminal en thème sombre, aucune donnée
client ni identifiant visible (flouter clés de tickets et emails réels si besoin).
